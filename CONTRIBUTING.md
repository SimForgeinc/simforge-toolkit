# Contributing

Open a pull request against this toolkit mirror with a reproducible example and the verification command. Maintainers review contributions, import accepted changes into the maintained source and export them back here; public changes are not merged automatically into the private source.

A contributor licence agreement is required before importing external contributions. Do not contribute proprietary runtime code, private infrastructure details, credentials, customer data, recorded-drive datasets or map and actor bytes. Protocol clients may depend on the documented runtime contracts, not on engine libraries or native Python bindings.

The build and Python installation commands are in [README.md](README.md). The separately distributed runtime is required for end-to-end local execution and RL training.
